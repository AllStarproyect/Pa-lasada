# Entregable 1

**¿Qué puede hacer un visitante sin registrarse en la plataforma?**

Puede visualizar y acceder a cualquier ventana, pero al momento de hacer checkout de productos en el carrito se le enviará a iniciar sesión / registrarse, de modo que se tengan datos de pago y envío.

**¿Qué ventajas o funcionalidades tendrá un usuario registrado frente a un visitante?**

Tendrá la ventaja de poder realizar la compra una vez registrado y recibir cupones exclusivos a su correo. En caso de no estarlo, el cliente tendrá la libertad de visualizar los productos y explorar la página, sin embargo no podrá proceder al pago.

**¿Qué información necesitamos conocer del cliente para realizar una compra?**

- Nombre
- Domicilio
- Método de pago
- Pedido

**¿El cliente podrá tener una o varias direcciones de entrega?**

El cliente podrá contar con diferentes direcciones de entrega, y podrá registrarlas con un nombre personalizado. Antes de realizar el pedido, se le pedirá al cliente confirmar la dirección de envío preferida. La primera dirección registrada será la predeterminada.

**¿Cómo se agregan los productos al carrito: por piezas, peso, presentación u otra modalidad?**

Por kilogramos y piezas (paquetes).

**¿Cómo se manejará el peso solicitado por el cliente cuando se trate de productos vendidos por peso?**

Por kilos.

**¿Puede el cliente modificar la cantidad o peso de un producto desde el carrito?**

Sí, puede modificarse la cantidad o peso de productos desde el carrito.

**¿Qué información debe mostrar el carrito antes de continuar con la compra?**

- Cantidad de productos totales y específicos
- Precio total
- Precio individual
- Dirección a donde se enviará o punto a recoger
- Método de pago preseleccionado
- Botón de confirmación

**¿Qué sucede si un producto agregado al carrito deja de estar disponible?**

Antes de proceder a la compra, se mostrará una etiqueta donde se explique que el producto dejó de estar disponible ("No disponible" / "Sin stock disponible"), mostrando el producto deshabilitado con un efecto opaco y dejando habilitado solo el botón de eliminar producto del carrito.

**¿Qué información debe proporcionar el cliente antes de confirmar el pedido?**

- Dirección
- Productos a comprar
- Métodos de pago preseleccionados o predefinidos
- Usuario

**¿Qué métodos de pago estarán disponibles inicialmente?**

- Efectivo / tarjeta contra entrega ($2,000 - definir límite)
- Tarjetas de crédito / débito
- Transferencias

**¿Qué condiciones deben cumplirse para considerar que una compra fue confirmada y se convirtió en un pedido?**

- Productos en el carrito
- Dirección de envío confirmada y seleccionada
- Método de pago seleccionado
